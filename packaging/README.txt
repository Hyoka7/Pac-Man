PAC-MAN (Linux x86_64)
======================

A Pac-Man style maze game written in Python with MiniLibX.
Collect every pacgum while four ghosts chase you through mazes
generated by the A-Maze-ing package. Clear all levels to win.


REQUIREMENTS
------------
- Linux x86_64 with an X11 display
- System libraries: libxcb, libxcb-keysyms, libvulkan, libbsd
- Sound is optional; without an audio device the game runs silently.
No Python installation is needed.


HOW TO START
------------
Unzip into a new, empty folder (the archive has no top-level folder),
then run:

    ./play.sh

With the itch app, press "Launch". To use another configuration file:

    ./play.sh path/to/other.json

The game takes exactly one argument, the configuration file.
play.sh passes config.json from this folder by default.


CONTROLS
--------
Home menu   Up/Down: select   Enter: confirm
            I: instructions   H: highscore ranking
Playing     Arrow keys or WASD: move
            P: pause          C: change maze colors
Paused      P: resume         H: back to the home menu
Ranking     Enter: back home  C: clear rankings (Y: yes, N: no)
Game end    Type your name (up to 10 letters, digits or spaces),
            Enter: save the score
Any screen  Esc: quit


RULES
-----
- Eat every pacgum to clear the level. Score and lives carry over.
- Super pacgums in the four corners make ghosts edible for 5 seconds.
- Touching a ghost costs a life; the game ends when no lives remain
  or when the level timer reaches zero.
- An eaten ghost goes back to its corner and waits 5 seconds.


CHEAT MODE (for evaluation)
---------------------------
Type 3 1 1 1 6 9 6 during play to turn cheat mode on or off.
While it is on:

    N  next level          F  freeze ghosts
    H  walk through walls  K  ghosts cannot hurt you
    V  speed up            L  one extra life
    T  10 more seconds     X  score x10

Turning cheat mode off cancels every active effect.


CONFIGURATION (config.json)
---------------------------
JSON with comments: lines starting with # are ignored.
Missing or invalid values are replaced by the default below and a
warning is printed. Unknown keys are ignored.

    highscore_filename       "scores.json"  file for the top 10 scores
    lives                    3              at least 1
    seed                     4              maze seed of level 1 (>= 1;
                                            42 if missing or invalid)
    points_per_pacgum        10             at least 1
    points_per_super_pacgum  50             at least 1
    points_per_ghost         200            at least 1
    levels                   10 levels      list of level objects:
        width                15             15 to 30
        height               15             15 to 30
        max_time             90             seconds, at least 90

Level 1 always uses the seed; later levels get a random maze.


HIGHSCORES
----------
The top 10 scores are saved in scores.json in this folder.
A missing or broken file is reported and the game starts with an
empty ranking.
