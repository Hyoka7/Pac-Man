# Pac-Man

PythonとMLXで制作中のPac-Manです。外部パッケージで生成した迷路を使い、移動・敵・アイテム・画面遷移を段階的に実装しています。

## 起動

現在のプロジェクト設定はPython 3.14以上です。`uv` と、MLXを表示できるX11のグラフィカル環境が必要です。

```bash
uv sync
uv pip install ./mazegenerator-2.1.0-py3-none-any.whl ./src/mlx-2.2-py3-none-any.whl
.venv/bin/python main.py
```

MLXと迷路生成パッケージは、現状では`pyproject.toml`の依存関係とは別に、同梱wheelからインストールします。

## 操作

| 画面 | キー | 動作 |
| --- | --- | --- |
| 共通 | Esc | 終了 |
| ホーム | Enter | 新しいゲームを開始 |
| プレイ中 | 矢印 / WASD | 移動、方向転換の予約 |
| プレイ中 | P | ポーズ |
| プレイ中 | C | 配色変更 |
| プレイ中 | N | 次レベルへ移動するテスト用操作 |
| ポーズ中 | P | 再開 |
| ステージクリア | 任意キー（Esc以外） | 次レベルへ |
| ゲームオーバー / 全クリア | ASCII英数字 | 名前を入力 |
| ゲームオーバー / 全クリア | Backspace | 名前の末尾を削除 |
| ゲームオーバー / 全クリア | Enter | 得点を保存してホームへ戻る |

ホームには保存済みランキングの先頭5件を表示します。

## 現在のゲーム動作

- 10レベル構成で、各レベルの制限時間は90秒。次レベルでは迷路を再生成します。
- プレイヤーは中央に最も近い通路から開始し、残機は3。次レベルへスコアと残機を引き継ぎます。
- 通常gumは10点。四隅のスーパーgumは30点で、5秒間敵を食べられます。
- パワーアップ中は敵が青くなり、逃走Strategyで移動します。食べた敵は200点となり、その敵の初期位置へ戻ります。
- ポーズ中は移動、レベルの残り時間、パワーアップの残り時間が止まります。
- 通常gumとスーパーgumをすべて食べるとステージクリア。最終レベルなら全クリアです。
- 時間切れはゲームオーバー。ただし同じフレームで最後のgumを食べた場合はクリアを優先します。
- HUDにレベル、得点、残機、制限時間を表示し、パワーアップ中は下部に残り時間と中央へ縮むバーを表示します。

これらの数値は現在の実装値です。設定ファイルからの適用は今後の作業です。

## ハイスコア

`HighscoreManager`は作成時に、実行時のカレントディレクトリにある`scores.json`を読み込みます。ファイルがなければ空のデータから始め、得点追加時に降順へ並べ替えて保存します。

Pydanticの`ScoreEntry`（名前と得点）と`HighscoreData`を使います。

```json
{
  "scores": [
    {"name": "Alice", "score": 1200},
    {"name": "Bob", "score": 800}
  ]
}
```

現在同梱の`scores.json`は開発中のテストデータです。読み込み時はファイルの並び順を維持します。破損ファイルや読み書き失敗への対応、入力の長さ・空名・得点の範囲の検証は未実装です。

## 構成

| ファイル | 役割 |
| --- | --- |
| `main.py` | 迷路生成と起動 |
| `visualize/maze_visualizer.py` | MLXの管理、入力、ゲーム進行、描画呼び出し |
| `visualize/maze.py` | 迷路、移動可否、中央付近の配置、全通路からのBFS距離表 |
| `visualize/movement.py` | セル間の移動と方向変更 |
| `visualize/player.py` | プレイヤー、得点、残機、パワーアップ |
| `visualize/ghost.py` / `strategy.py` | 敵の描画・移動と方向選択 |
| `visualize/pacgums.py` | 通常gumとスーパーgumの配置・消費・描画 |
| `visualize/collision.py` | 接触判定 |
| `visualize/gui.py` | 各画面、ランキング、HUD、バーの表示 |
| `visualize/highscore.py` | 得点モデルとJSONの保存・読み込み |
| `visualize/visualizerutils.py` | 画像バッファとピクセル描画 |
| `playground.py` | 特殊メソッドの練習用。ゲーム本体とは独立 |
