## 新しい環境での配置

CC0の`playing.ogg`は同梱する。Pixabayの音源ファイルをそのまま公開リポジトリへ配布する条件は未確認のため、`menu_bgm.mp3`と`pacgum.mp3`は同梱しない。上の各ページから利用条件を確認して手動でダウンロードし、このディレクトリに記載のファイル名で置く。

現在は3音源がそろっている前提で起動する。Pixabayの音源が未配置の場合は、音源の読み込みエラーになる。
